What is included?

Runs started through Bella: chats, delegated agents, Family chat, Today, and Research Lab. Tracking starts with this update. Earlier runs and sessions started separately in other apps or Terminal are not imported.

Codex reports a conversation counter. We subtract the counter at the start of this run, so earlier conversation usage is not charged to every new reply. Open “Check this count” below a Codex run to see the calculation. If the starting counter cannot be verified, the count stays unknown.

Unknown counts show a dash. Totals add only reported values and can be incomplete, especially after an interrupted run. Cached input is part of input, not an extra total. Token counts cannot be converted directly into your subscription percentage.

Only usage metadata is saved locally. Prompts, responses, and API keys are not stored in this usage history. Refreshing this page does not call an AI model.
